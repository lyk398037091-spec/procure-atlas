# ProcureAtlas - Product Decisions

## Non-negotiable independence
This project is an independent manufacturer-discovery product. It is not built to promote, seed, rank, or route traffic to any company owned or operated by the project sponsor.

## Initial vertical
Packaging machinery in China, aimed primarily at international B2B buyers.

## Product principle
The platform should answer **which manufacturer fits a procurement requirement and why**, with evidence, rather than publish generic “top manufacturer” lists.

## Ranking principle
Paid placement must never silently modify organic matching. Sponsored placements, if introduced later, must be labelled.

## Evidence principle
A company profile is not a factory audit. Every capability should eventually have claim-level source evidence and a checked date.

## Architecture principle
Version 0.1 is statically generated and deploys directly to GitHub Pages. Data lives as structured JSON. Phase 2 moves operational data to Supabase while retaining the static publishing pipeline for search visibility.
